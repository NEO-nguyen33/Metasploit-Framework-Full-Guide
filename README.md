## 🔧 What is Metasploit?

Metasploit is an open-source penetration testing framework used to **discover**, **exploit**, and **validate vulnerabilities** on systems.

It includes:

- Exploits
- Payloads (reverse shells, meterpreter, etc.)
- Auxiliary scanners
- Post-exploitation modules
